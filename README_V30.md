# V30 Trade Confirmation & Execution Preparation

Run: `python -m streamlit run app.py`

1. Select the symbol in the sidebar.
2. Open **V30 Trade Confirmation** and refresh market evidence.
3. Optionally fetch the desired expiry chain from **V15 Live Options Intelligence** first; V30 will reuse the session snapshot.
4. Review timeframe bias/freshness, options PCR/OI/Max Pain, headline risk, blockers and checklist.
5. The ATR ticket is a cash-equity sizing illustration only. Review all values before any external broker action.

No trade execution, broker order placement, probability estimate, or guaranteed forecast is included. Yahoo Finance history may be delayed/limited; Upstox option data depends on local credentials, permissions and successful fetch.
